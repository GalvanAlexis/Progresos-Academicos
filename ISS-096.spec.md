# ISS-096: Sabor Academy -- Plataforma E-learning de Cocina Infantil

## Objetivo

Crear una demo funcional de plataforma educativa e-learning/LMS dentro del catalogo de ejemplos de bladoPC. El nicho es cocina para ninos de 9 a 12 anos, con tono profesional pero divertido, estilo libro interactivo con mascota de gato negro chef.

---

## Alcance

- Demo 100% frontend (datos hardcodeados + localStorage para estado mutables)
- Sin backend real, sin autenticacion real (login simulado como los otros ejemplos)
- Sigue el patron de los ejemplos existentes (contable, landing, blog, delivery)
- Responsive: mobile-first, desktop hasta 1440px
- Tema claro (cocina natural, off-white), sin dark mode propio

---

## Estructura de Datos

### AdminState (useAdmin.ts -- localStorage key `sabor-admin`)

```typescript
interface AdminState {
  alumnoNombre: string;
  alumnoAvatar: string; // 'cat' | 'dog' | 'rabbit' | 'bear' | 'fox' | 'owl'
  cursos: Curso[];
  badges: Badge[];
  progreso: Record<string, CursoProgreso>; // key: cursoId
  adminAutenticado: boolean;
}

interface Curso {
  id: string;
  titulo: string;
  descripcion: string;
  dificultad: 1 | 2 | 3;   // llamitas
  duracion: number;          // cantidad de lecciones
  imagen: string;            // URL de Unsplash
  lecciones: Leccion[];
  quiz: Quiz;
}

interface Leccion {
  id: string;
  titulo: string;
  ingredientes: string[];
  utensilios: string[];
  pasos: Paso[];
  tips: string[];            // tips del gato
  imagen: string;            // URL de Unsplash
  completada: boolean;
}

interface Paso {
  numero: number;
  texto: string;
  imagen?: string;
}

interface Quiz {
  preguntas: Pregunta[];
  completado: boolean;
  puntaje: number;
}

interface Pregunta {
  texto: string;
  opciones: string[];
  correcta: number;          // indice 0-3
  explicacion: string;
}

interface Badge {
  id: string;
  nombre: string;
  icono: string;             // emoji o SVG
  descripcion: string;
  obtenido: boolean;
}

interface CursoProgreso {
  leccionesCompletadas: number;
  quizCompletado: boolean;
  certificadoObtenido: boolean;
}
```

### Cursos Predefinidos (hardcodeados, no editables desde admin)

Los cursos, lecciones, quizzes y badges vienen con datos de ejemplo por defecto. El admin permite editar **textos, URLs de imagen y arrays**, pero no agregar/eliminar cursos enteros (simplificacion).

## Flujos

### Flujo principal
1. Usuario llega a `/ejemplos/elearning`
2. Ve Hero con imagen de cocina + CTA + gato mascota
3. Hace click en "Empezar a cocinar" o scrollea al grid de cursos
4. Ve 5 tarjetas de cursos con dificultad (llamitas) y progreso
5. Click en un curso -> vista detalle del curso con lista de lecciones
6. Click en una leccion -> vista paso a paso con ingredientes, utensilios, pasos y tips
7. Al completar todas las lecciones se habilita el quiz
8. Al aprobar el quiz -> badge desbloqueado + certificado
9. El progreso se persiste en localStorage

### Flujo admin
1. Click en icono de engranaje / "Admin" en la Nav
2. Modal de login: user=`admin`, pass=`sabor123`
3. Dashboard con CRUD de cursos, lecciones, quizzes
4. Datos persisten en localStorage

## Componentes

### Nav.tsx
- Fijo arriba, altura 56px, fondo blanco con borde inferior suave
- Izquierda: logo "Sabor Academy" con icono de gorro de chef + gato mini
- Derecha: nombre del alumno, avatar, badges (iconos chicos), boton Admin
- En mobile: colapsa a icono de hamburguesa con slide-in panel

### Hero.tsx
- Full-width, min-h-[60vh], imagen de fondo de cocina (Unsplash: `https://images.unsplash.com/photo-1556909114-f6e7ad7d3136`)
- Overlay oscuro suave (rgba 0,0,0,0.4)
- Texto centrado: titulo grande + subtitulo + CTA naranja
- Mascota del gato negro SVG flotando desde la esquina inferior derecha
- Animacion sutile de entrada (fade-in)

### CoursesGrid.tsx
- Section con titulo "Nuestros Cursos"
- Grid 3 columnas (2 tablet, 1 mobile)
- Cada card: imagen 16:9, nombre del curso, dificultad (1-3 llamitas), duracion, barra de progreso
- Click abre CourseDetail

### CourseDetail.tsx
- Banner con foto del plato + nombre + dificultad + duracion
- Lista de lecciones con estado (pendiente/completada)
- Al completar todas: boton "Tomar Quiz"
- Si quiz aprobado: badge + certificado

### LessonView.tsx
- Encabezado con nombre de leccion + foto
- Seccion ingredientes (checklist con fotitos mini)
- Seccion utensilios (iconos)
- Pasos numerados con fotos
- Tips del gato en banner naranja con icono de gato
- Boton "Completar Leccion" al final

### QuizCard.tsx
- Modal overlay con pregunta actual
- 4 opciones en botones, feedback inmediato (verde/rojo)
- Explicacion al fallar
- Al final: resumen de puntaje, boton "Reintentar" o "Seguir"
- Confetti (CSS) al aprobar con 3/4 o mas

### ProfileCard.tsx
- Dropdown/modal con avatar seleccionable (6 opciones)
- Nombre editable inline
- Nivel actual (calculado por XP: cursos completados * 100)
- Barra de XP
- Badges obtenidos en grid

### ProgressBar.tsx
- Barra horizontal con color verde de relleno
- Texto: "3 de 5 cursos completados"

### Certificate.tsx
- Modal con diseno tipo pergamino
- Nombre del alumno, nombre del curso completado, fecha
- Sello de Sabor Academy, mascota del gato
- Botones: "Descargar" (simulado), "Cerrar"

### AdminDashboard.tsx
- Modal full-screen con tabs:
  - Cursos: editar nombre, descripcion, dificultad, imagen URL
  - Lecciones: editar titulo, ingredientes (texto plano, uno por linea), pasos, tips
  - Quizzes: editar preguntas, opciones (una por linea), respuesta correcta
  - Badges: editar nombre, descripcion
- Boton "Restablecer datos" (reset a defaults)

### Footer.tsx
- Minimalista: "Sabor Academy -- Un ejemplo de plataforma e-learning por BladoPC"
- Links a /servicios y a otros ejemplos
